## Diccionario de Variables `final.csv`

Este documento describe cada columna presente en `final.csv`, su origen, fórmula (cuando aplica), unidades y notas relevantes. Agrupado por categoría temática.

### 1. Identificadores y Localización
- **OBJECTID**: Identificador interno original de `neighborhoods.csv`.
- **name**: Nombre del barrio / vecindario.
- **geo_id**: GEOID del tracto censal (formato ACS: `1400000US...`) obtenido geocodificando el centroide (Census Geocoder). Puede no existir para áreas especiales.
- **latitude_centroid / longitude_centroid**: Coordenadas del centroide del barrio usadas para geocodificar.
- **surface_area**: Área del barrio en km² (fuente `neighborhoods.csv`). Puede diferir del área del tracto.

### 2. Demografía y Socioeconomía (ACS 5-year 2023)
- **acs_population**: Población total del tracto (ACS B01003_001E). Usada como base para tasas.
- **median_household_income**: Ingreso medio del hogar en USD (ACS B19013_001E). Valores como `250000+` truncados a `250000`.
- **average_age**: Edad promedio (proxy) = edad mediana (ACS B01002_001E), en años.
- **families_with_children_percentage**: (% hogares con menores <18) = (B11005_003E + B11005_005E + B11005_007E) / B11005_001E * 100. Porcentaje 0–100; categorías seleccionadas para evitar doble conteo.
- **rent_vs_own_percentage**: (% viviendas ocupadas por inquilinos) = B25003_003E / B25003_001E * 100. Porcentaje 0–100.
- **unemployment_rate**: Tasa de desempleo población 16+ (S2301_C04_001E) en %. Sanitizada 0–100.
- **education_level_percentage**: % población 25+ con Bachelor o superior (S1501_C02_015E). Fallback calculado si falta: S1501_C01_015E / S1501_C01_001E * 100. Sanitizado 0–100.
- **population_density**: Personas por km² = B01003_001E / surface_area. Aproximación (área barrio ≠ área tracto).

### 3. Vivienda (ACS 5-year 2023)
- **median_rent**: Renta bruta mediana mensual (USD) (B25064_001E). Valores con `+` (p.ej. `3,500+`) se limpian quitando `+` y comas.
- **median_home_price**: Valor mediano de vivienda ocupada por propietario (USD) (B25077_001E). Sujetos a márgenes de error altos en zonas con pocas muestras.
- **average_housing_age**: Antigüedad promedio estimada = 2023 - (mediana año construcción B25035_001E). Si resultado <0 o >300 → NaN.

### 4. Crimen (neighborhoods_crimen.csv + ACS población)
- **total_crimes**: Total anual de incidentes reportados (violentos + propiedad, según dataset).
- **violent_ratio**: Proporción de incidentes violentos = violent_crimes / total_crimes.
- **property_ratio**: Proporción de incidentes contra la propiedad = property_crimes / total_crimes.
- **violent_vs_property_ratio**: Relación entre proporciones = violent_ratio / property_ratio (si property_ratio>0; si no NaN).
- **crime_trend_slope**: Pendiente estimada de la tendencia temporal (incidentes/año). Negativa indica disminución.
- **crimes_per_100_people**: (total_crimes / acs_population) * 100. Zonas con población muy baja pueden inflar la tasa.

### 5. Notas Generales de Calidad y Sanitización
- Porcentajes fuera de rango (<0 o >100) y divisiones por cero → NaN.
- Población extremadamente baja (ej. parques) produce densidades y tasas de crimen atípicas; considerar excluir si `acs_population < 500` en análisis comparativos.
- Uso de mediana como proxy de promedio (edad y año construcción) por disponibilidad en ACS.
- GEOIDs de áreas especiales pueden carecer de ciertos datos → valores faltantes.
- Scripts idempotentes: `add_median_household_income.py`, `add_remaining_indicators.py`, `add_crime_indicators.py`, `add_housing_indicators.py`.

### 6. Fuentes
- ACS 5-Year 2023: Tablas B19013, B01003, B01002, B11005, B25003, S2301, S1501, B25064, B25077, B25035.
- Census Geocoder API para resolución GEOID.
- Dataset de crimen: `neighborhoods_crimen.csv` (estructura propia) + población ACS para normalización.
